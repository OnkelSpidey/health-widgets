Welche Daten die App nutzt

Nach deiner Zustimmung liest Health Widgets über die Google Health API ausschließlich lesend:

  • Aktivität: Schritte und Kalorien (googlehealth.activity_and_fitness.readonly)
  • Gesundheitswerte: Puls, Ruhepuls, Herzfrequenzvariabilität, Atemfrequenz (googlehealth.health_metrics_and_measurements.readonly)
  • Schlaf: Schlafdauer und Schlafphasen (googlehealth.sleep.readonly)

Wo die Daten bleiben

Die Daten werden nur auf deinem iPhone verarbeitet und dort zwischengespeichert, damit Widgets sie anzeigen können. Es gibt keinen Server des Entwicklers. Die Daten werden nicht weitergegeben, nicht verkauft, nicht für Werbung genutzt und nicht zum Trainieren von KI-Modellen verwendet.

Anmeldedaten

Die Zugangsschlüssel von Google werden im geschützten Schlüsselbund (Keychain) deines iPhones gespeichert.

Widerruf und Löschung

Du kannst die Verbindung jederzeit in der App trennen oder den Zugriff unter myaccount.google.com/permissions widerrufen. Mit dem Löschen der App werden alle lokal gespeicherten Daten entfernt.

Google API Services User Data Policy

Die Nutzung und Weitergabe von Informationen, die über Google-APIs empfangen werden, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).
